# 大语言模型原理

大语言模型是一种**概率统计**模型，根据给定`词`的上下文，预测最可能的下一个`词`。（词语接龙机器！）

## 原理

大语言模型基于 Transformer 架构①。Transformer 本质上是一套“**放弃词语顺序，采用全局关联**”的深度神经网络①，其核心是注意力机制。

**注意力机制**

注意力机制的底层逻辑是用数学计算**全局关联**。

## 训练

大模型训练的本质就是在做“完形填空”。

```
X ————W1————> H1 ————W2————> H2 ————W3————> y^^ ————> L
```

**前向传播 & 向量化 & 注意力值**

词的最终表示是一个**高维向量**，其计算过程会考虑所有其它词向量（向量点积——方向一致性的度量），因此被称作（相互）注意力值。

```
Q = X·W^Q, K = X·W^K, V = X·W^V

Attention(Q, K, V) = Softmax( (Q·K^T) / √d_k ) · V

X_new = X_old + Attention(Q, K, V)

注：在最一开始（神经网络的第一层），X、W^Q、W^K、W^V 被随机初始化。
```

注意力值最终会体现出**语义关联性**，即词与词的关联强度，但注意语义关联性并不是近义词的意思，语义关联性指的是，一段语言文字中**词语共现**的概率，也就是在一个词出现的情况下，另一个词大概率也会出现的关联情况。

训练就是逐步调整权重值（`W^Q`、`W^K`、`W^V`），最终得出每个词的注意力值的过程。那具体如何调整呢？

**反向传播 & 梯度下降 & 残差连接**（模型是如何学习的？）

当模型预测有偏差的时候（通过损失函数衡量），反向传播机制（纠错机制）启动，根据损失值进行逆运算，最终精准地传导回权重值 `W^Q`、`W^K`、`W^V`，然后进行调整（梯度下降），`X`也会被相应地更新（残差连接），从而改进预测结果③。

```
∇_WL = ∂L/∂W

W_new = W_old − η ⋅ ∇_WL

注：η 是常数，代表学习率；L 代表损失值；∇_WL 代表梯度，是针对权重值 W^Q、W^K、W^V 的改进指导。
```

训练就是在词向量空间中为每一个词找到具有语义关联性的位置（词向量），也就是所谓的**词嵌入**。训练的最终结果是向量空间中的一张“语义地图”，而且这张地图还是超高维的。

*注③：实际训练中，会涉及多层神经网络，还涉及多头注意力，但注意力值计算逻辑一致；需要注意反向传播也涉及回溯多层网络。*

## 生成

大模型在回答问题时，根本不“理解”问题，它只是在不断寻找下一个词，学术上叫**自回归生成**。

**自回归生成 & 条件概率**

自回归生成，是指在“输出层”输出的可能作为**下个词**的概率列表里面，选择一个**条件概率**最大（实际可能涉及采样策略等）的词作为下一个词，然后把这个新选择的词也加入到条件里，继续寻找下一个词（迭代式的，或回归式的），直到结束。
