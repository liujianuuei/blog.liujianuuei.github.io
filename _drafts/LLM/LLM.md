# 大语言模型原理

大语言模型①是一种**概率统计**模型，根据给定`词`（局部前文），预测最可能的下一个`词`。

## 概述

大语言模型基于 Transformer 架构②。Transformer 本质上是一套深度神经网络③，其核心是自注意力机制。

#### 自注意力机制

自注意力机制的底层逻辑是用数学计算**全局关联**④（所有词都能“看到”所有词，这就是人类语言的特点）。

## 训练，或模型学习

一个典型的模型执行路径是多层网络堆叠的，前层输出作为后层输入，每层都是同构的，比如`X1 ————W2————> X2`（其含义可以符号化表示为`X2 = W2 · X1`）就是相对独立的一段。后续概念都以单层为例说明，全链路同理⑤。

```
X0/输入层 ————W1————> X1/隐藏层 ————W2————> X2 ————W3————> ...... ————Wn————> Xn ————LMH/输出层————> Y/原始输出结果 ····Softmax····> y-hat ····CrossEntropy····> L

注：Y 为词表大小，代表原始输出结果（Logits）；y-hat 为归一化后模型预测值；L 代表损失值；W 代表每层参数向量矩阵；X 代表每层输入和输出的词向量，这些向量中的每个标量元素对应一个神经元，初始 X，即 X0 是从词表矩阵 W_E 获取的。LMH 代表 LM Head。
```

#### 前向传播 & 向量化 & 自注意力 & 前馈网络 & 残差连接

词的表示是一个来自于向量空间的**高维向量**，其计算过程会考虑向量空间（词序列）前文所有词向量（向量点积——方向一致性也即相关性的度量），因此被称作自（“自”的含义体现于向量空间或词序列内部相互注意）注意力机制。

```
X_0 = W_E[token化索引] # W_E 是词表矩阵，真实公式其实为 X_0 = One-hot(token) · W_E
```

```
自注意力部分:

Q = X·W^Q, K = X·W^K, V = X·W^V  # K 和 V 其实是矩阵，在实际计算过程中，涉及一个操作动作，即从缓存中读取前文所有词的 K 和 V，然后组装成矩阵。至于为什么可以使用缓存的“旧版本”，是因为自注意力的因果掩码限定。

Attention(Q, K, V) = Softmax( (Q·K^T) / √d_k ) · V

X_n+0.5 = X_n + Attention(Q, K, V)

前馈网络部分:

FFN1(X) = X·W_1 + b_1

Activation(X) = ReLU(FFN1(X))

FFN2(X) = Activation(X)·W_2 + b_2

X_n+1 = X_n+0.5 + FFN2(X_n+0.5)


注：X 是词向量，W_E、W^Q、W^K、W^V、W_1、W_2 是参数向量矩阵，b_1、b_2 是偏置项，在最一开始，被随机初始化。
```

自注意力机制⑥最终会让词向量体现出上下文**语义关联性**，即词与词的关联强度。语义关联性并不是近义词的意思，语义关联性指的是，一段语言文字中**词语共现**的概率，也就是在一个词出现的情况下，另一个词大概率也会出现的关联情况。具有语义关联性的词在向量空间中方向更近。

前馈网络⑦相当于是一个存储**世界知识**的知识库，而且某种程度上是静态的，也就是说大语言模型还是会静态记忆一些东西。前馈网络本质是给当前自注意力值（`X_n+0.5`）增加**深层语义**知识，这些知识没有直接体现也无法体现在当前自注意力值里，但具有深层关联。自注意力值经过前馈网络**非线性变换**，就是最终输出到下一层的词向量`X_n+1`了。

需要注意👀的是，词向量`X_n+1`是动态计算的（当然`X_0`是静态赋值的），这就是大语言模型能动态感知词语上下文（解决同词异义现象，根据词所在词序列语境调整向量，准确区分多义词的不同含义）的原因。

**每层**都是这样，然后经过层层叠加，词向量越来越抽象、越来越深刻，其语言信息已包含语法、语义、常识和深层逻辑等全部信息。最终再转化为对每个词作为下一个词的概率预测（`y-hat`）。

```
Y = X_n · W_LMH + b_LM  # 最后一个词的最终表征（X_n），完全决定了下一个词的选择（Y 或者 y-hat）；最终预测只看最后一个词，但最后一个词是前文所有词在自注意力机制下合力造就的。

y-hat = Softmax(Y)

注：W_LMH 是词表矩阵，也就是 W_E，包含全部词语；b_LM 是偏置项；y-hat 就是归一化后的每一个词的概率。
```

话说回来，模型训练就是逐步调整参数（`W_E`、`W^Q`、`W^K`、`W^V`、`W_1`、`W_2`、`b_1`、`b_2`、`W_LMH`、`b_LM`），最终得出符合预期的`y-hat`的过程。那具体如何调整呢？

#### 反向传播 & 链式法则 & 梯度下降（模型是如何学习的？）

通过前向传播过程，我们可以看出大语言模型作为一种深度神经网络，本质上是一个超多层的**复合函数**（函数套函数）。损失值（预测值`y-hat`和真实值`y`的差距，记为 `L`）对这个最终的复合函数值的变化率，也就是对该复合函数求偏导，而复合函数的导数等于各层导数之积（链式法则），所以就相当于**反向逐层求偏导**，也就是计算各层参数对总损失值（`L`）的贡献度（梯度），也就是所谓的反向传播。

```
链式法则:

z = f(y,a), y = g(x,b)

∂z/∂x = ∂z/∂y · ∂y/∂x
```

反向传播是一种纠错机制。根据链式法则，损失值会传递回每一层，每层都有自己的梯度，每层都需要更新相应的参数，朝着梯度增加的反方向更新，也就是所谓的梯度下降，这样让损失减少，从而改进预测结果。

```
L = -∑_i=1^V y_i · log(y-hat_i) => −log(y-hat_ytrue)  # 损失函数，交叉熵公式


根据: ∇_WL = ∂L/∂W  # 符号化表示，实际计算并非如此，而是通过链式法则

链式法则推导如下:

L→Y:              ∂L/∂Y  # 应用链式法则，反向传播的起点

Y→W_LMH:          ∂L/∂W_LMH = (∂L/∂Y) · (∂Y/∂W_LMH)
Y→X_n+1:          ∂L/∂X_n+1 = (∂L/∂Y) · (∂Y/∂X_n+1)

前馈网络部分:

X→W_2:            ∂L/∂W_2 = (∂L/∂X_n+1) · (∂X_n+1/∂W_2)
X→b_2:            ∂L/∂b_2 = (∂L/∂X_n+1) · (∂X_n+1/∂b_2)

X→Activation:     ∂L/∂Activation = (∂L/∂X_n+1) · (∂X_n+1/∂Activation)

Activation→FFN1:  ∂L/∂FFN1 = (∂L/∂Activation) ⊙ (∂Activation/∂FFN1)

FFN1→W_1:         ∂L/∂W_1 = (∂L/∂FFN1) · (∂FFN1/∂W_1)
FFN1→b_1:         ∂L/∂b_1 = (∂L/∂FFN1) · (∂FFN1/∂b_1)

FFN1→X_n+0.5:     ∂L/∂X_n+0.5 = (∂L/∂FFN1) · (∂FFN1/∂X_n+0.5)

自注意力部分:

X_n+0.5→QK:       ∂L/∂QK = (∂L/∂X_n+0.5) · (∂X_n+0.5/∂QK)

QK→Q:             ∂L/∂Q = (∂L/∂QK) · (∂QK/∂Q)
QK→K:             ∂L/∂K = (∂L/∂QK) · (∂QK/∂K)

Q→W^Q:            ∂L/∂W^Q = (∂L/∂Q) · (∂Q/∂W^Q)
K→W^K:            ∂L/∂W^K = (∂L/∂K) · (∂K/∂W^K)

Q→X_n:            ∂L/∂X_n = (∂L/∂Q) · (∂Q/∂X_n)
K→X_n:            ∂L/∂X_n = (∂L/∂K) · (∂K/∂X_n)
Q+K→X_n:          ∂L/∂X_n = (∂L/∂Q) · (∂Q/∂X_n) + (∂L/∂K) · (∂K/∂X_n)

...

词表矩阵部分（在训练完成后，词表矩阵 W_E 跟其它参数向量矩阵一样，就是固定不变的了，然后在模型生成的时候，W_E 被用来初始化词向量）:

X_0→W_E:          ∂L/∂W_E = (∂L/∂X_0) · (∂X_0/∂W_E)


更新参数向量矩阵(这里就是模型学习发生的地方✍🏻):

W_new = W_old − η ⋅ ∇_WL


注：η 是常数，代表学习率；L 代表损失值；∇_WL 代表梯度，是针对参数向量矩阵的改进指导。
```

模型训练好后，`W_E`、`W^Q`、`W^K`、`W^V`、`W_1`、`W_2`、`b_1`、`b_2`、`W_LMH`、`b_LM`不再发生变化，智能就封存在这些参数里。需要注意的是，`W_E`作为词表矩阵，这时候，其实已经具有一般意义上的丰富语义了，再加上前向传播时词向量`X`动态计算，语义就更丰富准确了。

#### 一个具体的模型训练的例子

上面是底层数学原理，我们来看一个具体的例子。模型训练的时候，大量原始文本通过分词、拼接与切块后，变成固定长度的词（token，本文不区分词和词元，两者混用）序列，然后输入模型，模型需要预测词序列里**每个位置**的**下一个词**。

比如，输入词序列🛼：`我` `喜` `欢` `学` `习` `轮` `滑` `。`

模型会生成如下预测任务：

- 看到`我`，预测下一个词应该是`喜`；
- 看到`我喜`，预测下一个词应该是`欢`；
- 看到`我喜欢`，预测下一个词应该是`学`；
- 看到`我喜欢学`，预测下一个词应该是`习`；
- 看到`我喜欢学习`，预测下一个词应该是`轮`。
- 看到`我喜欢学习轮`，预测下一个词应该是`滑`。
- 看到`我喜欢学习轮滑`，预测下一个词应该是`。`。

模型是没有“句子”概念的，所以“随机断句”根本不影响模型的训练效果，反而是训练场景之一，这样训练出来的模型，随便半句话，它都能往后续。切断导致的局部信息缺失，也就是上下文不足，会通过全局概率统计弥补，输出最常见的搭配，而当上下文足够时，会输出更精准的预测。

最终，所有**出现过**（在各种文档或训练语料里）的词语搭配（或词序列），模型都“见过”了，也“习得”了这些搭配出现的概率，它也就“学会”了，也就可以开始和你对话了。那么，当和模型开始对话，输入一个问题的时候，模型是如何工作的呢？

## 生成，或模型推理

和模型对话的过程，也就是模型生成或推理的过程，这个过程和训练时候的前向传播完全一样，只是不再进行反向传播而已。

#### 理解（局部）前文

这一步就是前向传播逐个词计算直到最后一个词向量`X`的过程⑧，最后一个词的词向量会蕴含前文的所有语义信息。

#### 寻找下一个词（在一门语言的词表里）

这一步就是前向传播计算`Y`和`y-hat`的过程，最后一个词的`y-hat`中概率最大（实际可能涉及采样策略等）的词，就是要找的下一个词。

接着，把找到的词作为最后一个词，循环执行上面两步，进行下一轮生成（单向地，自回归生成），直到终止。

## 总结

大语言模型是基于**线性代数**、**微积分**、**概率论**的超大规模工程实现。回顾整个过程，最不可思议的地方在于**人类语言的可计算性**。
