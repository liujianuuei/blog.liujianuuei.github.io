# 大语言模型原理

大语言模型是一种**概率统计**模型，根据给定`词`的上下文，预测最可能的下一个`词`。

## 概述

大语言模型基于 Transformer 架构①。Transformer 本质上是一套“**放弃词语顺序，采用全局关联**”的深度神经网络①，其核心是注意力机制。

#### 注意力机制

注意力机制的底层逻辑是用数学计算**全局关联**。

## 训练

一个典型的模型执行路径是多层网络堆叠的，前层输出作为后层输入，每层都是同构的，比如`X1 ————W2————> X2`（其含义可以符号化表示为`X2 = W2 · X1`）就是相对独立的一段。后续概念都以单层为例说明，全链路同理。

```
X0/输入层 ————W1————> X1/隐藏层 ————W2————> X2 ————W3————> ...... ————Wn————> Xn ————LMH/输出层————> Y/原始输出结果 ····Softmax····> y-hat ····CrossEntropy····> L

注：Y 为词表大小，代表原始输出结果（Logits）；y-hat 为归一化后模型预测值；L 代表损失值；W 代表每层权重向量；X 代表每层输入和输出的词向量，这些向量中的每个标量元素对应一个神经元。LMH 代表 LM Head。
```

#### 前向传播 & 向量化 & 注意力值 & 前馈网络 & 残差连接

词的最终表示是一个**高维向量**，其计算过程会考虑所有其它词向量（向量点积——方向一致性的度量），因此被称作（相互）注意力值。

```
Q = X·W^Q, K = X·W^K, V = X·W^V

Attention(Q, K, V) = Softmax( (Q·K^T) / √d_k ) · V

X_n+0.5 = X_n + Attention(Q, K, V)

FFN(X) = Activation(X·W_1 + b_1)·W_2 + b_2

X_n+1 = X_n+0.5 + FFN(X_n+0.5)

注：在最一开始，X、W^Q、W^K、W^V、W_1、W_2、b_1、b_2 被随机初始化；初始化后，第一层 X 不会变化，其它层 X 会被相应地更新，即残差连接。
```

注意力值③最终会体现出上下文**语义关联性**，即词与词的关联强度，注意语义关联性并不是近义词的意思，语义关联性指的是，一段语言文字中**词语共现**的概率，也就是在一个词出现的情况下，另一个词大概率也会出现的关联情况。

前馈网络相当于是一个存储**世界知识**的知识库，而且某种程度上是静态的，也就是说大语言模型还是会静态记忆一些东西。前馈网络本质是给当前注意力值（`X_n+0.5`）增加**深层语义**知识，这些知识没有直接体现也无法体现在当前注意力值里，但具有深层关联。注意力值经过前馈网络④**非线性变换**，就是最终的输出词向量`X`了。

每层是这样，然后经过层层叠加，词向量越来越抽象、越来越深刻，其语言信息已包含语法、语义、常识和深层逻辑等全部信息。最终转化为对每个词的概率预测（`y-hat`）。

```
Y = X_n · W_LMH + b_LM

y-hat = Softmax(Y)

注：W_LMH 是词表矩阵，包含全部词语；b_LM 是偏置项；y-hat 就是归一化后的对应每一个词的概率。
```

话说回来，模型训练就是逐步调整权重向量（`W^Q`、`W^K`、`W^V`、`W_1`、`W_2`、`b_1`、`b_2`、`W_LMH`、`b_LM`），最终得出符合预期的`y-hat`的过程。那具体如何调整呢？

#### 反向传播 & 链式法则 & 梯度下降（模型是如何学习的？）

通过前向传播过程，我们可以看出大语言模型作为一种深度神经网络，本质上是一个超多层的**复合函数**（函数套函数）。损失值（预测值`y-hat`和真实值`y`的差距，记为 `L`）对这个最终的复合函数值的变化率，也就是对该复合函数求偏导，而复合函数的导数等于各层导数之积（链式法则），所以就相当于反向**逐层求偏导**，也就是计算各层权重向量（`W`）对总损失值（`L`）的贡献度（梯度），也就是所谓的反向传播。

```
链式法则

y = f(u), u = g(x), y = f(g(x))

dy/dx = dy/du ⋅ du/dx
```

反向传播是一种纠错机制。根据链式法则，损失值会传递回每一层，每层都有自己的梯度，每层都需要更新相应的权重向量（`W^Q`、`W^K`、`W^V`、`W_1`、`W_2`、`b_1`、`b_2`），朝着梯度增加的反方向更新，也就是所谓的梯度下降，这样就让损失减少了，从而改进预测结果。

```
L = -∑_i=1^V y_i · log(y-hat_i) => −log(y-hat_ytrue) # 损失函数，交叉熵公式


根据:   ∇_WL = ∂L/∂W

链式法则推导如下:

L→Y:   ∂L/∂Y # 应用链式法则，反向传播的起点

Y→X:   ∂L/∂X = (∂L/∂Y) * (∂Y/∂X)
       ∂L/∂W_LMH = (∂L/∂Y) * (∂Y/∂W_LMH)

X→QK:  ∂L/∂QK = (∂L/∂X) * (∂X/∂QK)

QK→Q:  ∂L/∂Q = (∂L/∂QK) * (∂(QK)/∂Q)
QK→K:  ∂L/∂K = (∂L/∂QK) * (∂(QK)/∂K)

Q→W^Q: ∂L/∂W^Q = (∂L/∂Q) * (∂Q/∂W^Q)
Q→W^K: ∂L/∂W^K = (∂L/∂K) * (∂K/∂W^K)


更新权重向量(这里就是模型学习发生的地方✍🏻):

W_new = W_old − η ⋅ ∇_WL


注：η 是常数，代表学习率；L 代表损失值；∇_WL 代表梯度，是针对权重向量 W^Q、W^K、W^V 的改进指导。
```

模型训练好后，`W^Q`、`W^K`、`W^V`、`W_1`、`W_2`、`b_1`、`b_2`、`W_LMH`、`b_LM`不再发生变化，智能就封存在这些参数里。那么，当和模型开始对话，输入一个问题的时候，模型是如何工作的呢？

## 生成

大模型在回答问题时，根本不“理解”问题，它只是在不断寻找下一个词，学术上叫**自回归生成**。`X`、`Attention(Q,K,V)`、`Y`、`y-hat`是针对当前问题的具体“思考过程”。

生成的时候，执行一次前向传播，建立起一个语义向量空间。对于一个给定的词，可以准确对应到该向量空间里的一个具有深层语义关联性的“位置”（`y-hat`），也就是所谓的**词嵌入**过程。

它把原本无法被神经网络直接处理的文字，转化为包含语义信息的向量表示，让语义相近的词汇在高维空间中距离更近，解决了传统编码无法体现词汇语义关联的问题。
‌
和早期静态词嵌入不同，大模型生成的是上下文相关的动态嵌入，能根据词语所在的句子语境调整向量，精准区分“银行”这类多义词的不同含义。

动态修正

针对同词异义是一个向量还是多个向量。

具体训练是输入什么样的文本。

生成下一个词是只看前一个词还是前面的都看

同样由多层结构堆叠而成，但比编码器多了一个交叉注意力层。它的任务是自回归地（Autoregressive）生成输出序列

#### 自回归生成 & 条件概率

自回归生成，是指在“输出层”输出的可能作为**下个词**的概率列表里面，选择一个**条件概率**最大（实际可能涉及采样策略等）的词作为下一个词，然后把这个新选择的词也加入到条件里，继续寻找下一个词（迭代式的，或回归式的），直到结束。

## 总结

大语言模型是基于**线性代数**、**微积分**、**概率论**的超大规模工程实现。
