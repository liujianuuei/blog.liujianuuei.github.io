# 大语言模型原理

大语言模型是一种**概率统计**模型，根据给定`词`的上下文，预测最可能的下一个`词`。（词语接龙机器！）

## 原理

大语言模型基于 Transformer 架构①。Transformer 本质上是一套“**放弃词语顺序，采用全局关联**”的深度神经网络①，其核心是注意力机制。

**注意力机制**

注意力机制的底层逻辑是用数学计算**全局关联**。

## 训练

大模型训练的本质就是在做“完形填空”。一个典型的模型执行路径是多层网络叠加的。

```
X0 ————W1————> X1 ————W2————> X2 ————W3————> y^^ ————> L

注：y^^ 为模型预测值；L 代表由损失函数计算的损失值，是基于 y（基准真值）和 y^^ 计算出来的；W代表权重向量值；X 代表模型的神经网络层。
```

**前向传播 & 向量化 & 注意力值 & 残差连接**

词的最终表示是一个**高维向量**，其计算过程会考虑所有其它词向量（向量点积——方向一致性的度量），因此被称作（相互）注意力值。

```
Q = X·W^Q, K = X·W^K, V = X·W^V

Attention(Q, K, V) = Softmax( (Q·K^T) / √d_k ) · V

X_n+1 = X_n + Attention(Q, K, V)

注：在最一开始，X、W^Q、W^K、W^V 被随机初始化；初始化后，第一层 X 不会变化，其它层 X 会被相应地更新，即残差连接。
```

注意力值最终会体现出**语义关联性**，即词与词的关联强度，但注意语义关联性并不是近义词的意思，语义关联性指的是，一段语言文字中**词语共现**的概率，也就是在一个词出现的情况下，另一个词大概率也会出现的关联情况。

训练就是逐步调整权重向量值（`W^Q`、`W^K`、`W^V`），最终得出每个词的注意力值的过程。那具体如何调整呢？

**反向传播 & 梯度下降**（模型是如何学习的？）

当模型预测有偏差的时候（通过损失函数衡量），反向传播机制（纠错机制）启动，根据损失值进行“逆运算”，最终精准地传导回权重向量值 `W^Q`、`W^K`、`W^V`，然后进行调整（梯度下降，损失减少），从而改进预测结果③。

```
∇_WL = ∂L/∂W

W_new = W_old − η ⋅ ∇_WL

注：η 是常数，代表学习率；L 代表损失值；∇_WL 代表梯度，是针对权重向量值 W^Q、W^K、W^V 的改进指导。
```

训练就是在词向量空间中为每一个词找到具有语义关联性的位置（词向量），也就是所谓的**词嵌入**。训练的最终结果是向量空间中的一张“语义地图”，而且这张地图还是超高维的。

___________________________________________________

*注③：需要注意，反向传播除了单层“逆运算”，也涉及回溯多层网络（链式法则），也就是每层都有自己的梯度，每层都需要更新权重向量值。*

## 生成

大模型在回答问题时，根本不“理解”问题，它只是在不断寻找下一个词，学术上叫**自回归生成**。

**自回归生成 & 条件概率**

自回归生成，是指在“输出层”输出的可能作为**下个词**的概率列表里面，选择一个**条件概率**最大（实际可能涉及采样策略等）的词作为下一个词，然后把这个新选择的词也加入到条件里，继续寻找下一个词（迭代式的，或回归式的），直到结束。

**动态修正**

针对同词异义是一个向量还是多个向量。

激活函数

```
ReLU(x) = max(0,x)

FFN(X) = ReLU(X·W_1 + b_1)·W_2 + b_2
```
